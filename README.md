# 📄 AI Resume Analyzer & ATS Score Checker

An AI-powered Resume Analyzer that uses NLP and Machine Learning to evaluate resumes against job descriptions.

## 🚀 Features

✅ Upload Resume PDF  
✅ Extract Resume Text  
✅ NLP Based Text Processing  
✅ Skill Extraction  
✅ ATS Compatibility Score  
✅ Resume & Job Description Matching  
✅ Missing Skill Detection  
✅ Improvement Suggestions  


## 🛠 Technologies Used

- Python
- Machine Learning
- Natural Language Processing
- TF-IDF Vectorization
- Streamlit
- Scikit-learn
